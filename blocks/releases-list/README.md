# releases-list

Custom block (no library base). Purpose: dated list of ASX releases with a client-side pager (Previous, page numbers, Next) and a "Showing x–y of N" count.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first row: Page size | number (default 10); then one row per release: date cell (plain text, e.g. 19 November 2026) | title cell (link, or plain text).

## Supported variations

No variations.

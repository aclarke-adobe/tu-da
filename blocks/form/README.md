# form

Custom **custom** block. Purpose: web form with text inputs, selects, checkboxes and a submit button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: either a link to a form definition sheet (.json: Name, Label, Type, Options, Mandatory, Placeholder, Value, Help) or rows of Label | Type | Options | Mandatory | Placeholder; plus optional Action, Submit and Success rows and free text rows.

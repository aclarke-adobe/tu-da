# cards-overlay

Custom **cards** block. Purpose: photo tiles with heading, text and link overlaid; tiles without a photo render as boxed text tiles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional image cell | body cell (heading, text, optional link).

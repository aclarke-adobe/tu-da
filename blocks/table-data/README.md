# table-data

Custom **table** block. Purpose: bordered data table with a header row.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per table row, one cell per column; first row is the header row when there is more than one row.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |
| Header (source `<th>` row: grey fill, black semibold text) | `header` |
